# Monitoring Scope

## Covered

- Codex and ChatGPT Work usage limits
- Credits and entitlement changes
- Model availability and routing behavior
- Reset lifecycle
- Official incidents
- Stable releases and shipped features
- Capacity and admission changes

## Not Covered

- General AI news
- Unverified social speculation
- Individual user complaints without evidence threshold
- Predictions of future product decisions

## Runtime principle

The workflow monitors state transitions, not conversations.
