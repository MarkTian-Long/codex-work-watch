# Codex Work Watch

A high-signal monitoring workflow for Codex and ChatGPT Work availability, routing, credits, capacity and reset lifecycle.

This project is not a news feed. It tracks meaningful product-state changes.

Notifications are limited to official changes, shipped releases, scope changes, rollback/restore events, or lifecycle transitions.

Core principles:

- official sources first;
- evidence before alerts;
- silent by default;
- lifecycle-aware monitoring;
- no CLI-to-Desktop extrapolation.

The repository contains prompts, policies and schemas. Runtime state remains external to GitHub.
